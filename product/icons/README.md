# Icons

One SVG per icon (24 x 24, `currentColor`, 1.5 px strokes), `sprite.svg` with every icon as a `<symbol id="fs-name">`, `android/` with each as a VectorDrawable (`fs_name.xml`, tinted by the theme), and `sf-symbols/` with each as an SF Symbols custom symbol for iOS and watchOS (`fs.name`). Rules in `product/foundations.md#icons`.
