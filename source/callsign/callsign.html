    Source

    The names are the IAU's own: the Current List of IAU Star Names on the IAU's Naming Stars page, kept by its Working Group on Star Names. Positions are J2000 in degrees, as the IAU gives them; vmag is the visual magnitude it lists.

    A browser can't read the IAU page directly (the IAU doesn't allow it), so this page checks the copy in the fusionspace-design repository, which callsign update reads from the IAU. Nothing else leaves the browser.

    Command line

    The same tool for a terminal, on macOS, Linux and Windows (and phones with a Python app): one file, Python 3.8 or later, no dependencies, the list built in. It reads the IAU list again by itself when its copy is over 30 days old.

    python3 callsign.py                            # draw a star (on Windows: py callsign.py)
python3 callsign.py -n 5 -c Orion --vmag ..3   # five bright stars in Orion
python3 callsign.py list --max-letters 5       # every short name
python3 callsign.py show Vega                  # one star
python3 callsign.py update                     # read the IAU list now
python3 callsign.py --help                     # everything else: --json, --plain, --skip
