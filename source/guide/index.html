FusionSpace

An identity for aerospace engineering projects, drawn from how stars are classified. Four stars sit in one cluster, and a soft gradient runs across them from cool M-class orange to hot O-class blue.

SHEET 1 / 7

The mark

This is the original 2023 cluster, redrawn with exact geometry. Each star is the space left between four touching circles, so the tips come to true points. The three companions are 0.45, 0.40 and 0.32 the size of the main star, placed where the first sketch had them. One gradient sweeps across the whole cluster, so the west star comes out warm and the east star cool.

Same cluster, cleaner

The layout and sharp tips match the first sketch. Every edge is a true circular arc, and logo/mark/fusion-space-mark-50mm.dxf carries the exact arcs for FreeCAD, laser and CNC work.

One sweep

The gradient always runs left to right, from M orange to O blue, across the full width of the cluster.

Three modes

Use the gradient version wherever color prints. Use one-color Void or white for engraving, stamps, laser cutting and single-color vinyl.

SHEET 2 / 7

Lockups

The wordmark is FusionSpace, one word, set in Cascadia Mono SemiBold with the same gradient. It's outlined in every file.

Clear space

Keep 0.25 H clear on every side, where H is the height of the star cluster.

Minimum size

Cluster: 24 px or 8 mm tall. Below 48 px, as in favicons, use the main star on its own.

Proportions

Horizontal: cap height 0.30 H, gap 0.22 H. Stacked: cap height 0.295 H, gap 0.14 H.

Color

Fusion gradient

The brand's signature color. It runs from class M to class O, passing through rose and lavender so the middle stays soft instead of turning gray.

Spectral

The source palette, sampled from the Harvard classification's Vega-relative chromaticity. Use it for charts and graphics, not for text on light backgrounds.

Core

Signal

Deep versions of O and M that pass WCAG AA for text on Paper. On dark backgrounds, use the gradient ends instead.

Graphic elements

Files & tools

Everything opens in free software.

logo/Mark, lockups and wordmark as Inkscape SVG, in color, void and white versions. Each star is its own named path. There's also a 50 mm DXF of the mark with exact arcs, for cutting. Transparent PNGs are in logo/png, and the favicon set is in logo/favicon.
color/fusion-space.gpl palette for Inkscape and GIMP, including the gradient stops, plus CSS and JSON tokens.
type/fonts/Cascadia Mono and Archivo TTFs with their OFL licenses.
graphics/Mark construction drawing, gradient strip and spectral bar.
templates/GitHub social card, plus FreeCAD TechDraw sheets in ANSI A, ANSI B and A4.
tools/christen/Christen, the star name tool: christen.html for any browser, phones included, and christen.py for a terminal, with the IAU star list as JSON and CSV.
_archive/The original Illustrator and SolidWorks files, plus the Rev A single-star set.

Setup

  1. Install every font in type/fonts (double-click, then Install).
  2. Inkscape palette: copy color/fusion-space.gpl to ~/Library/Application Support/org.inkscape.Inkscape/config/inkscape/palettes/, then restart Inkscape and pick “FusionSpace” in the Swatches panel.
  3. FreeCAD: in TechDraw, choose Insert Page using Template and pick a sheet from templates/freecad. The title-block fields show up under the page's Editable Texts.
  4. Each logo file has a hidden, locked “live text” layer. To edit the wordmark, unhide that layer. Otherwise leave the outlined version as it is.
